// features

Your Mac fights back.

Four layers of defense. The thief won't know what hit them.

⚡

Charge Monitor

Polls every 2 seconds. The instant your charger is pulled, the alarm triggers. No delay.

📸

Instant Photo

Camera stays warm during monitoring. Captures the thief's face in milliseconds, not seconds.

📨

Telegram Alert

Photo + timestamp sent straight to your phone. You'll know before the alarm even stops ringing.

🔒

Anti-Tamper

Runs as root. Traps kill signals. Only your login password can stop the alarm. A thief can't.

// how it works

Three commands. Zero worries.

01

Plug in & configure

Install with brew install imagesnap then run toilet setup to link your Telegram bot. One-time setup, takes 2 minutes.

02

Arm it

At the café? Plug in your charger and run sudo toilet. Camera warms up. Monitoring starts.

03

Go do your thing

Bathroom. Phone call. Whatever. If the charger moves, you get a photo on Telegram and the whole café hears about it.

// install

Get it running.

⌥ One-liner

# Install toilet + camera tool
curl -sL https://raw.githubusercontent.com/dzulfikar08/toilet/main/install.sh | bash
brew install imagesnap

# Configure & run
toilet setup
sudo toilet

⌘ Manual

  1. Clone the repo
  2. Copy toilet to /usr/local/bin/
  3. brew install imagesnap
  4. toilet setup — configure Telegram
  5. toilet test — verify everything
  6. sudo toilet — arm it
